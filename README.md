# Retail Customer Behaviour Analytics Using Python, SQL & Power BI

## 📌 Project Overview
This project focuses on analyzing customer shopping behavior using Python, SQL, and Power BI. The goal is to understand customer purchasing patterns, product category performance, discount usage, and subscription trends to generate useful business insights.

## 🎯 Project Objectives
- Analyze customer purchasing behavior and spending patterns.
- Clean and prepare data for accurate analysis.
- Use SQL queries to answer business questions.
- Create an interactive Power BI dashboard.
- Identify trends and opportunities to support business decisions.

## 🛠️ Tools and Technologies
- **Python:** Data cleaning and exploratory data analysis (EDA)
- **Pandas and NumPy:** Data processing and manipulation
- **SQL:** Data querying and business analysis
- **PostgreSQL:** Database management
- **Power BI:** Interactive dashboards and data visualization
- **Excel:** Initial data inspection
- **GitHub:** Project documentation and version control

## 📂 Project Workflow

### 1. Business Understanding
Defined business questions related to customer shopping habits, spending, product categories, discounts, and subscriptions.

### 2. Data Cleaning Using Python
Used Python and Pandas to inspect the dataset, check missing values and duplicates, standardize data, and prepare the data for analysis.

### 3. Exploratory Data Analysis (EDA)
Explored customer demographics, purchase amounts, product categories, review ratings, and shopping preferences to understand patterns in the data.

### 4. SQL Analysis
Used SQL queries, aggregate functions, subqueries, Common Table Expressions (CTEs), and window functions to analyze purchasing trends, customer segments, discount usage, and subscription behavior.

### 5. Power BI Dashboard
Designed an interactive dashboard to present key performance indicators (KPIs), customer trends, category performance, and spending patterns through charts and visualizations.

### 6. Insights and Reporting
Interpreted the analysis results to identify business opportunities and present findings in a clear, understandable format.
